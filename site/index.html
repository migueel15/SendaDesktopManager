Senda

Senda es un gestor de escritorio para Wayland: una CLI y una barra Quickshell, actualmente para Arch Linux con Hyprland.

Código fuente: github.com/migueel15/SendaDesktopManager

Qué incluye

  • Control de fondos de pantalla.
  • Notificaciones.
  • Widget de voz de Discord.
  • Gestión del foco de ventanas.

Instalación

curl --proto '=https' --tlsv1.2 -fsSL https://migueel15.github.io/SendaDesktopManager/install.sh | sh

Tras instalar, ejecuta senda setup.
